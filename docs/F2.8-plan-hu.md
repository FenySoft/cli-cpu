# F2.8 — TT-chip perifériák FPGA-validáció

## Cél

A Tiny Tapeout (F3) chipbe szánt **perifériák** megépítése (TDD) és **valós FPGA-n** (MicroPhase A7-Lite XC7A200T) történő validálása a tapeout **előtt**. A projekt alapelve szerint: *„nincs silicon tape-out olyan design-nal, ami nem futott FPGA-n."* Ugyanaz a logika, mint az F2.7-nél (egymagos core FPGA-validáció) — az új RTL hibáit olcsón, FPGA-n fogjuk ki, nem a szilíciumon.

## Kontextus

- **F2.7 kész:** a Nano core (single thread, 32-bit wide datapath) FPGA-validált — Fibonacci(20)=6765 az A7-Lite-on.
- **F3 cél:** host-vezérelt, betölthető CIL-T0 csomópont a TT IHP shuttle-ön, ami valós szilícium-proof + következtetés-forrás + Symphact-substrate.
- A TT chip a **wide 32-bit termék-architektúra hű példánya** (a soros datapath véglegesen elvetve — a mérések különben nem transzferálnának a termékre).
- Az F3-hoz **új perifériák** kellenek, amelyek még nem futottak FPGA-n → ez az F2.8 hatóköre.

## Hatókör

**Benne:** UART RX, boot-over-UART loader, Mailbox FIFO, GPIO MMIO, trace MUX, IRQ logika, FPGA-integráció (A7-Lite wrapper), QSPI Pmod validáció.

**Nincs benne:** barrel MT (multi-thread) — a single-core wide marad az első chiphez; a multi-aktor scheduling az F4 FPGA mérföldkőre tartozik. Az IHP szintézis (teljes chip) az F2.6, a tapeout az F3.

## Komponensek + TDD sorrend

Minden komponens **szigorú TDD**: RED cocotb teszt először → futtatás (BUK) → implementáció → GREEN → integráció → regresszió. A meglévő minták: `cilcpu_divider.v`/`test_divider.py`, `cilcpu_multiplier.v`/`test_multiplier.py`, `uart_tx.v`/`test_uart_tx.py`.

### F2.8.1 — UART RX
- **Interfész:** `i_rx` (soros) → `o_data[7:0]` + `o_valid` (1-ciklus pulzus) + `o_frame_err`. 8N1, konfigurálható `CLOCKS_PER_BAUD` (mint a `uart_tx`).
- **RTL:** `rtl/fpga/uart_rx.v` (vagy `rtl/src/` ha core-közeli).
- **TDD:** `rtl/tb/test_uart_rx.py` — start-bit detektálás, 8 adatbit mintavételezés (bit-közép), stop-bit, framing error, back-to-back byte-ok.

### F2.8.2 — Boot-over-UART loader
- **Cél:** a host UART RX-en keresztül betölt egy CIL-T0 programot a memóriába (PSRAM), majd elindítja a core-t. Lecseréli a jelenlegi hardkódolt `BOOT_ARG_VALUE` generic-et.
- **Protokoll (javaslat):** `magic (2B) | length (4B) | payload (N×B) | boot_pc (3B) | arg_count (1B) | local_count (1B) | args (arg_count×4B) | CRC`.
- **RTL:** loader FSM a wrapperben — fogadja a byte-okat, PSRAM-ba írja (QSPI write), majd `i_boot_*` jeleket hajtja a core felé.
- **TDD:** `rtl/tb/test_uart_loader.py` — protokoll-keret fogadás, PSRAM-írás verifikáció, boot-trigger, CRC-hiba kezelés.

### F2.8.3 — Mailbox FIFO
- **Interfész:** inbox + outbox, 8 mély, MMIO `0xF000_0100` (a CIL program `LDIND`/`STIND`-del éri el). Külső `o_irq_out` (outbox nem üres) + `i_irq_in` (host jelez).
- **RTL:** `rtl/src/cilcpu_mailbox.v` — két FIFO + MMIO bus interfész + IRQ generálás.
- **TDD:** `rtl/tb/test_mailbox.py` — push/pop, full/empty flag, FIFO-mélység, MMIO read/write, IRQ pulzus.

### F2.8.4 — GPIO MMIO
- **Interfész:** MMIO `0xF000_0200` — bemeneti pinek olvasása (`GPIO_IN`), kimeneti pinek írása (`GPIO_OUT`), irány/oe regiszter. A CIL aktor pineket olvas/hajt.
- **RTL:** `rtl/src/cilcpu_gpio.v`.
- **TDD:** `rtl/tb/test_gpio.py` — input-olvasás, output-írás, oe-vezérlés, MMIO bus.

### F2.8.5 — Trace MUX
- **Interfész:** konfigurálható MUX (MMIO `0xF000_0300` vagy boot-pin) → a kiválasztott belső jelcsoport (PC, FSM-állapot, stack-mélység, ALU-eredmény, mailbox-foglaltság) a kimeneti pinekre. Mód-megosztott a GPIO-val.
- **RTL:** `rtl/src/cilcpu_trace.v` — jel-mux + mód-kapcsoló.
- **TDD:** `rtl/tb/test_trace_mux.py` — mux-kiválasztás minden jelcsoportra, mód-váltás GPIO↔trace.

### F2.8.6 — IRQ logika
- **Cél:** mailbox/külső interrupt in/out jelek a host↔chip async jelzéshez (wake/response latencia mérés).
- **RTL:** kis FSM a wrapperben (mailbox IRQ + external event). A core jelenleg trap-alapú; az IRQ a mailbox-állapotból + külső pinből származik.
- **TDD:** `rtl/tb/test_irq.py` — IRQ-out pulzus outbox-íráskor, IRQ-in latch + nyugtázás.

### F2.8.7 — FPGA-integráció (wrapper)
- A perifériák bekötése egy bővített A7-Lite top-levelbe (a `cilcpu_a7lite_top.v` mintájára) — clock/reset, memory bus arbiter (core + loader + mailbox + GPIO + trace MMIO), pin-kiosztás.
- A wrapper a TT `tt_um` interfész **funkcionális ekvivalense** (24-pin logikai leképezés), hogy az F3 wrapper minimális átírással következzen.

## FPGA-validáció (A7-Lite)

### cocotb (szimuláció)
- Komponens-szintű: a fenti `test_*` tesztek mind zöld.
- Integrált: `test_a7lite_*` bővítve — a teljes wrapper a perifériákkal.

### Valós hardver (A7-Lite + QSPI Pmod)
- **QSPI Pmod** bedugva az A7-Lite PMOD-csatlakozójába → **ugyanaz a memória-hardver** (W25Q128 flash + 2× APS6404L PSRAM), mint a TT-n → a dual-CS QSPI controller + flash/PSRAM viselkedés valós HW-en bizonyított.
- **Boot-over-UART:** host betölt egy CIL-T0 programot UART-on → fut → eredmény UART-on vissza.
- **GPIO:** a CIL aktor olvas gombokat, hajt LED-eket (A7-Lite onboard LED/gomb).
- **Mailbox echo:** host → mailbox → CIL aktor feldolgozza → outbox → host (echo neuron demó), IRQ-latencia mérve.
- **Trace:** belső jelek a PMOD-header-en logikai analizátorral → ciklus-pontos FPGA↔(későbbi)szilícium korreláció alapja.

## Kész kritérium

- [ ] Minden periféria cocotb tesztje zöld (TDD RED→GREEN igazolva)
- [ ] Integrált wrapper cocotb-regresszió zöld (a meglévő core-tesztek + az újak)
- [ ] A7-Lite-on fizikailag fut: boot-over-UART betöltés → CIL-T0 program végrehajtás
- [ ] GPIO: aktor olvas bemenetet + hajt kimenetet (LED/gomb) valós HW-en
- [ ] Mailbox echo demó fut UART-on, IRQ-latencia mérve
- [ ] QSPI Pmod (flash + PSRAM) működik az A7-Lite-on
- [ ] Trace busz kiad belső jeleket (logikai analizátorral ellenőrizve)

## Függőségek

- **Bemenet:** F2.7 kész (core FPGA-validált), F2.6-prep MUL/DIV szekvenciális (kész).
- **Kimenet → F2.6:** a validált teljes chip (core + perifériák + wrapper) szintetizálható IHP-re → **valós tile-szám**.
- **Kimenet → F3:** a validált, tile-méretezett design → TT tapeout.

## Kapcsolódás a roadmaphoz

```
F2.7 (core FPGA, kész)
   → F2.8 (perifériák FPGA-validáció)   ← EZ
       → F2.6 (teljes chip IHP szintézis, valós tile-szám, NLnet M1)
           → F3 (TT tapeout, NLnet M2)
```

Megjegyzés: a bare-core **F2.6 szintézis párhuzamosan futtatható MOST** (baseline tile-szám, nincs hozzá új RTL) — ez keretezi, mennyi tile marad a perifériáknak.

## MMIO cím-térkép (javaslat, véglegesítendő)

| Cím | Blokk |
|-----|-------|
| `0xF000_0100` | Mailbox (inbox/outbox FIFO) |
| `0xF000_0200` | GPIO (in/out/oe) |
| `0xF000_0300` | Trace MUX konfiguráció |

A `cilcpu_defines.vh` MMIO régiója `0xF000_0000` — ezek alá esnek.
